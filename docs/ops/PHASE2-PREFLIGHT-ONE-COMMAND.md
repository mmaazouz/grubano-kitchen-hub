> **Cause racine de classe (deux lecteurs du même fichier).** Le chargeur runtime (`server.js`) est **STRICT** : `/^([A-Z_][A-Z0-9_]*)=(.*)$/` sur la ligne brute, **première** occurrence gagne, une ligne avec BOM / espace initial / `KEY = v` / `export KEY=v` n'est **pas** chargée.
