> Established 2026-09-05 on `develop` @ `d221008` by repository forensics (every `sendMail(` / `sendTransactional(` / `sendOnce(` call site read first-hand), public DNS queries, a read-only SMTP EHLO probe, and a deterministic render harness (`tools/render-current.test.ts`, 12/12 PASS, nothing sent). **No code, DNS, flag, Stripe, Claims or Refund state was modified.**
>
> **Evidence discipline (SOURCE / OBSERVED / REQUIRED):** a fact is either read in code (`file:line`), measured on staging (dated), or marked NOT MEASURED. Flags "default OFF" are code facts, not staging measurements, unless a dated measurement is cited.

## 0 · Reading the statuses

| Primary status | Meaning used here |
|---|---|
| **A LIVE_CODE_CONFIRMED_SEND** | reachable code path in the **current beta configuration** + actual send call + recipient resolution + template identified. "Reachable" includes manual/admin-triggered paths; a flag standing between the event and the send in the current config demotes to B. |
| **B CODE_EXISTS_NOT_SEND_PROVEN** | template + send call exist (unit-tested with mocked transport) but the send is **not reachable today**: behind a flag measured/defaulting OFF, behind an inert scheduler, or without any caller. The "NOTES" column names the exact gate. |
| **C CURRENT_BETA_TRAIN_CONFIRMED** | product behaviour locked for the beta, email not wired. **None found**: every locked behaviour either has a wired email or is an explicit *no-email* decision (recorded in `EMAIL-CLAIMS-REFUNDS-FACTS.md`). |
| **D DEAD_OR_ORPHANED** | unscheduled by founder decision, no caller, historical. |
| **E NOT_CONFIRMED** | insufficient evidence. **None**: every candidate was read to its send call. |

Common facts (not repeated per row): transport = one Nodemailer SMTP config (`SMTP_HOST` default `mail.grubano.com`, port 587, STARTTLS opportunistic, `SMTP_USER`/`SMTP_PASS`); From = `"Grubano" <contact@grubano.com>` (3 cron scripts use a different display name, same address); no Reply-To anywhere; HTML-only except the 3 rows marked `text ✓`; locale = **FR hardcoded** except the two localized families (claims ×5 + onboarding nudges ×5, RTL for `ar`); EmailLog row written per send by the rail (`sent|skipped|failed`), inline senders write their own row or none (see EMAIL-INFRASTRUCTURE §5).
